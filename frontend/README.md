### `npm run dev`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes.\
You may also see any lint errors in the console.

### 360 Panorama Downloads

After generating a panorama in the 360 Image workflow, choose a format below
the preview and use the download button:

- **JPEG (360 metadata):** Includes GPano XMP metadata identifying the image as
	a complete equirectangular panorama. Compatible panorama viewers can use it
	to recognize the 360 projection automatically.
- **PNG (lossless):** Downloads the original generated image without re-encoding.
	Select the 360 equirectangular projection manually when importing it.
